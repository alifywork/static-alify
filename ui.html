Swap the token block at the top of ui.css. shadcn publishes zinc, slate, stone, gray and neutral — drop in any of them and every component follows, because nothing is hard-coded to a colour.

09

Usage

Four tags in <head>, two before </body>.

Copy this into any page

Paths are relative to the repo root — prefix with ../ if your page is nested.

<!-- head: theme.js FIRST so there is no flash of the wrong theme -->
<script src="assets/ui/theme.js"></script>

<link rel="stylesheet" href="assets/geist/geist.css">
<link rel="stylesheet" href="assets/ui/ui.css">
<link rel="stylesheet" href="assets/fontawesome/css/all.min.css">
<meta name="color-scheme" content="light dark">

<!-- end of body -->
<script src="assets/ui/ui.js"></script>

<!-- theme API -->
<button data-ui-theme-toggle>Toggle</button>
UITheme.set('dark');   UITheme.getMode();   UITheme.cycle();

<!-- toast API -->
<script>UI.toast({ title: 'Saved', variant: 'success' });</script>
